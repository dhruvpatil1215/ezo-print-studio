⚙️ Printer Connection & Hardware Setup

ℹ️ The eZo 58D thermal printer supports Windows printer driver printing, Web Serial (USB/COM), and Bluetooth SPP/BLE depending on model configuration.
📱 Phone (Android) Bluetooth Setup (Step-by-Step)

Why direct browser Bluetooth fails: Almost all 58mm thermal printers (like eZo 58D) use Bluetooth Classic (SPP). Web browsers (Chrome, Edge, Samsung Internet) are strictly blocked from accessing Bluetooth Classic for security reasons.

Easy 2-Minute Solution for Android Phones:
1️⃣ Turn on printer. Go to phone Settings > Bluetooth and pair your printer (PIN is 0000 or 1234).
2️⃣ Install free RawBT Print Service from Play Store.
3️⃣ Open RawBT once > choose Bluetooth > select your paired printer.
4️⃣ Now in Ezo Print Studio, simply tap "📱 Android Bluetooth" or "🖨️ Print Receipt" to print over Bluetooth!

1. Standard Browser / Windows Driver Printing (Default)

Works with any thermal printer installed in Windows. Click Print, select your 58mm POS printer, and check "No Margins" in system print settings.

2. Web Serial API (Direct USB / COM Port)

Send raw ESC/POS text or raster image bytes directly from Chrome/Edge to your paired Bluetooth COM port or USB Serial port without third-party drivers.

3. Web Bluetooth API (BLE Thermal)

If your eZo printer has BLE (Bluetooth Low Energy), pair directly inside the browser. (Note: Classic Bluetooth SPP requires the COM-port method or native app).

4. Windows Python Bridge Helper

Included in your workspace folder windows/print_text.py. Run in PowerShell:

py windows/print_text.py COM5 "TEST PRINT"
